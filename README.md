## in - по ссылке, но только для чтения
Код с данным методом `Print` не компилируется, потому что метод пытается изменить значение параметра, переданного через `in`

## Шаг 2. ref - Swap
Метод Swap нельзя реализовать с обычными параметрами, потому что они не могут изменять значение вызывающей переменной

**Ответы на контрольный вопросы**
1. Для `int` копируется число, а для объекта класса - ссылка на объект
2. `ref` требует инициализировать переменную до вызова метода (изменяет существующую переменную), при использовании `out` переменную можно инициализировать во время вызова (присваивает значение переменной)
3. Потому что `out` нужен для записи нового значения, а не чтения старого
   Также это позволяет избежать ошибок при работе программы (если пользователь ввёл не число, `bool` вернёт `false`, а в `int` передастся значение 0)
4. in передаёт переменную только для чтения, запрещая её изменение. Он интереснее для больших структур, т.к. передача их значений обычным способом означает копирование всех их полей
5. Необязательные параметры должны находится после обязательных
6. Именованный аргумент позволяет не запутаться в том, для какого именно параметра мы передаём значение
